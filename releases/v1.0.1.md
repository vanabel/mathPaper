# Release v1.0.1

## Changes

- Add WinEdt UTF-8 headers to `main.tex` and `mathpaper.sty`:
  - `%% -*- mode: TeX -*-`
  - `%% -*- coding: utf-8 -*-`
- Add `\usepackage[utf8]{inputenc}` in `main.tex` for pdfLaTeX/WinEdt UTF-8 input.
- Make `make zip` **version-aware**:
  - `VERSION` variable (default: latest git tag, fallback `v0.0.0`)
  - output: `mathpaper-$(VERSION).zip`
- README: link to [AMSRefs-arXiv-Support](https://github.com/vanabel/AMSRefs-arXiv-Support).
- `.gitignore`: ignore `*.zip` and `.DS_Store`.

## Notes

- To build a versioned zip explicitly:

```bash
make zip VERSION=v1.0.1
```
