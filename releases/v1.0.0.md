# Release v1.0.0

Initial release of **mathPaper**: an `amsart`-based template for writing mathematical papers.

## Contents

- **main.tex** — Main document; edit "Paper metadata" and body.
- **mathpaper.sty** — Preamble bundle (layout, hyperref, amsrefs, theorems, cleveref, proof/step style).
- **references.bib** — Example bibliography (BibTeX); includes journal and arXiv examples.
- **amsrn.bst** — Numeric bibliography style (AMSRefs).
- **Makefile** — `make` (build PDF), `make clean` / `make distclean`, `make zip` (source + main.pdf).
- **README.md** — Usage, arXiv citation, single-file submission options.

## Features

- amsart + mathpaper.sty; optional single-file mode (inline preamble / .bbl).
- BibTeX + AMSRefs; for arXiv entries with `[math.DG]`-style suffix, use [AMSRefs-arXiv-Support](https://github.com/vanabel/AMSRefs-arXiv-Support).
